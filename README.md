# INFR 3120 - Assignment 1

This README file will describe some of the choices made throughout the project.

## Viewports

There are **three** viewports that I have designed my site for which include smartphones, tablets, and full size desktop computers and other large screen sizes. Smartphones have a _maximum_ width of **480 pixels**, tablets have a width _between_ **480 and 960 pixels**, and the full size devices have a width that is _at least_ **960 pixels**. These sizes were chosen based on the **Week 3** material covered in the Week3.pdf, where it describes the common viewports and their sizes.

The general decisions that I have made to make the website easier to use for smaller screens is that I made it so pictures and text are in a singular column style. I thought that it would have looked too congested within the page for the images to be on the left and having very small text due to the smaller size on the right, so I put the text from paragraphs under the images. On smartphones, this makes sense as people mainly scroll vertically through pages since their height often greater than width, so more content is able to be included on screen. The text within these pages is also larger to handle the fact that the screens are smaller relative to the page, and so that the image related to the text is never fully off screen so users can still have relevant visuals for what they are reading.

With images specifically, I have almost always made their widths **100%** on smartphones and tablets because of the smaller size and the empty space on the side of the screen would not look good. The width being this size also does not really stretch the images much, because they have a large size to begin with, and the screens of these devices are not very large.

Most of the changes described above apply to the **Projects Page** because that page has the most text and images of all pages, and is the most important to optimize because of it.

## Linear Gradient and Color Scheme

For the **linear gradient**, this is used on _all pages_ going from left to right from a light blue to a light purple/pink mix. It is also used in the _navigation bar_. Once I decided to use it on one page's background, I wanted to use it on the background of every page to keep the site's look consistent. This is also why the text follows the color scheme, because I thought it would look strange for everything to not be in the color scheme and less cohesive. All _headings_ are **purple** shades and all _text_ is **blue** shades. I used blue shades for the text as the gradient goes from left to right and blue to purple, so a darker blue would stick out enough on the blue part of the background, and also the purple part of the background. The blue part of the gradient is lighter than the text color, and the text color is darker than the purple part, so the contrast makes it readable.

The color scheme is also useful for many images I used because I found that it is dark enough for the lighter colored images like the house on the Projects Page, while also being light enough for the Ember Bear logo on the same page.
